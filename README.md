# Projet Machine Learning – Prédiction du prix de location d'un appartement

## 1. Présentation

Ce projet consiste à développer un modèle de Machine Learning capable de prédire le prix de location d'un appartement à partir de ses caractéristiques.

## 2. Objectifs

- Explorer et comprendre les données immobilières.
- Nettoyer et préparer les données.
- Identifier les variables explicatives du prix.
- Construire plusieurs modèles de régression.
- Évaluer et comparer les performances.
- Identifier le modèle le plus performant.

## 3. Organisation du projet

- `data/` : données du projet.
- `notebooks/` : notebooks Jupyter.
- `src/` : scripts Python.
- `models/` : modèles entraînés.
- `reports/` : graphiques et résultats.
- `requirements.txt` : dépendances Python.

## 4. Technologies
